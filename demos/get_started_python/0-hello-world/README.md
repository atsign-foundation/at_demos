# get_started_python

## 1. Install the `atsdk` dependency from [PyPi](https://pypi.org/project/atsdk/0.1.0/)

```bash
pip install atsdk
```

## 2. Run main.py

```bash
python main.py
```

### Non-Working Output

```bash
➜  0-hello-world git:(jt/get_started) ✗ python3 main.py
atsdk is invalid:  No module named 'at_client'
```

### Working Output

```bash
➜  0-hello-world git:(jt/get_started) ✗ python3 main.py
atsdk dependnecy is valid!
```
